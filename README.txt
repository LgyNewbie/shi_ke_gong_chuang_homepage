食客共创：首页练习版

使用方法：
1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 选择这个文件夹作为项目目录。
4. AppID 可以先选择你自己的小程序 AppID；如果只是学习，可按开发者工具提示选择测试/无 AppID 方式。
5. 编译后可以直接看到首页。

本版本只做首页 UI：
- 顶部品牌区
- 食客留言
- 本周投票
- 餐厅公告
- 去点餐
- 写留言悬浮按钮
- 四个底部导航

暂时没有接数据库，点击其他页面会弹出提示，这是故意的。
下一步再创建点餐、订单、我的三个页面，并把导航真正连起来。

图片在 images 文件夹里，后面可以直接替换成你自己的图片，但文件名保持一致即可。
